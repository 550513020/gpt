# 水岸庭院 · 交互式三维漫游

- [电脑端](https://550513020.github.io/gpt/desktop.html?v=11)
- [手机横竖屏版](https://550513020.github.io/gpt/mobile.html?v=11)

点击「一键逛街」体验预算购物，也可选择目的地自动步行到达。自由行走支持 WASD、Q/E 升降，手机可用方向按钮和触摸拖动。

进入地下停车场后可点击「驾驶体验 · 驶向出口」。影院内可切换入场顶灯与放映模式。

静态 Three.js 概念建筑模型；购物、价格、航空及充电设施均为模拟，不产生实际支付。模型采用近远细节与自动画质，低配置设备可在目录里选择「流畅优先」。
